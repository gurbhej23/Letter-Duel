# Letter Duel — Frontend Client

Modern, responsive web application built with **React**, **Vite**, and custom **Vanilla CSS** with a dark cyber-arena aesthetic.

## Features
- **Gaming UI Aesthetics**: Dark cyberpunk theme with neon cyan and violet accents, glassmorphic HUD, and smooth transitions.
- **Web Audio API Synthesizer**: Rich, zero-dependency sound effects for clicks, key presses, hit/miss chimes, turn alerts, and victory fanfares with persistent mute toggle.
- **Strict Turn Indicators**: Dynamic neon pulsating banner communicating "YOUR TURN" vs "OPPONENT'S TURN".
- **Alphabet Keyboard**: Interactive virtual keys with hit (green) / miss (muted red) visual status indicators.
- **Discovered Letter Slots**: 3D embossed letter tiles revealing all occurrences of guessed letters (`_ A _ A _ A _`).
- **Real-Time Battle Chat**: Instant player messages and authoritative system events.
- **Modals**: How to Play tutorial with the Bananas vs Apple turn example, Global Leaderboard, Friends & Rivals manager, and Profile customization.

## Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Production build
npm run build
```
